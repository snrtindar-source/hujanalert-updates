Kebijakan Privasi HujanAlert Indonesia

Terakhir diperbarui: 28 Oktober 2026

1. Data yang dikumpulkan

HujanAlert Indonesia ("Aplikasi") mengumpulkan data yang sangat terbatas, hanya untuk menjalankan fungsinya:

  • Lokasi perangkat — hanya ketika Anda mengizinkan, untuk menentukan wilayah prakiraan cuaca, menampilkan peringatan BMKG di sekitar Anda, dan memposisikan Anda di peta radar. Aplikasi tidak melacak pergerakan Anda secara terus-menerus.
  • Wilayah yang Anda pilih — nama provinsi/kabupaten/kota yang Anda pilih secara manual.
  • Pengaturan — lokasi favorit, pengaturan alarm, dan preferensi tampilan.

2. Data yang TIDAK dikumpulkan

  • Aplikasi tidak meminta nama, alamat email, atau akun apa pun.
  • Aplikasi tidak mengumpulkan data analitik, iklan, atau pelacakan perilaku.
  • Koordinat GPS Anda tidak dikirim ke server pihak ketiga.

3. Penyimpanan data

Seluruh data (lokasi favorit, pengaturan, cache cuaca dan radar) disimpan hanya di perangkat Anda. Data tidak dikirim ke server pihak ketiga.

4. Layanan pihak ketiga

Aplikasi mengambil data cuaca dan peringatan dari API publik resmi BMKG (Badan Meteorologi, Klimatologi, dan Geofisika) serta layanan prakiraan cuaca terbuka. Permintaan data tersebut hanya berisi koordinat wilayah (kode wilayah), bukan lokasi presisi perangkat Anda.

5. Izin (permission) yang digunakan

  • Lokasi — untuk prakiraan dan peringatan di sekitar Anda.
  • Notifikasi — untuk alarm hujan dan peringatan cuaca.
  • Internet — untuk mengunduh data cuaca, radar, dan pasang surut.
  • Jeda layar (wake lock) — agar alarm hujan tetap berbunyi tepat waktu.

6. Anak di bawah umur

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak sengaja mengumpulkan data dari mereka.

7. Penghapusan data

Anda dapat menghapus lokasi favorit kapan saja dari dalam Aplikasi, atau menghapus seluruh data Aplikasi melalui Pengaturan Android (Aplikasi → HujanAlert → Hapus Data).

8. Perubahan kebijakan

Perubahan pada kebijakan ini akan diumumkan melalui pembaruan Aplikasi. Tanggal "Terakhir diperbarui" di atas selalu mencerminkan versi terbaru.

9. Kontak

Pertanyaan mengenai privasi dapat dikirim melalui saluran resmi HujanAlert Indonesia di Google Play Store (bagian "Hubungi kami" pada halaman Aplikasi).
